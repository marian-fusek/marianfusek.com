Changes appear automatically. CSS updates without reloading the page, so preview state and scroll stay put.

CODE ↔ PREVIEW

Click an element in the preview to jump to its HTML. Move through HTML to softly identify the matching preview element.

FORMAT + EMMET

Format keeps indentation tidy. In HTML/CSS, type an Emmet abbreviation and press Tab to expand it.

DIAGNOSTICS

Errors and warnings appear quietly in the gutter and footer. JavaScript reports exact runtime lines and messages.

Undo and redo survive reopening the editor. Drafts and interface preferences are also preserved locally.
