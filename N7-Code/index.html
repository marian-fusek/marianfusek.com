PROJECT + OUTPUT

FILES

Toggle the real project tree when you need it. Open folders keep their actual hierarchy; hide it again to return to the clean workspace.

PROJECT

Start fresh, open files, or open a real folder project. Folder projects keep their hierarchy and can be saved back to disk when the browser grants access. When switching projects, N7-Code protects the previous changes locally if direct folder saving is unavailable. PROJECT → RECOVER PREVIOUS appears whenever that recovery is available.

N7-CODE BACKUP

PROJECT → SAVE writes back to an opened writable folder. Otherwise it downloads a portable .n7-code backup. Older .mfcode backups still open.

EXPORT

Creates one standalone index.html containing your current HTML, CSS and JavaScript.

PREVIEW

Switch desktop, tablet and mobile widths, refresh manually, use Focus, or detach the live preview into its own browser window.

RECOVERY

If preview JavaScript breaks and blocks the page, RECOVER offers temporary preview-only actions such as hiding a loader or restoring scroll. Your project files are never changed.

TOOLS

Optional power stays tucked away: Format and Libraries live under TOOLS, and the same actions are available from the command palette.
