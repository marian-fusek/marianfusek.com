# Corndoggy Concepts Website

## Purpose
This is a lightweight presentation site for pitching digital Corndoggy product concepts. It should feel friendly, playful and simple, while staying clean enough for a quick business conversation.

## Product constraints
- Keep Corndoggy artwork at the center of every concept.
- Avoid concepts that require a social network, user-generated public feed, moderation, or a heavy backend.
- Prefer client-side/local-first experiences.
- Do not reintroduce Pick 'Em or Team Rooms unless explicitly requested.
- Current concepts are: Corndoggy Stickers, Corndoggy Maker, Corndoggy Bingo, Corndoggy Sunday Rules, Corndoggy Game Deck, Corndoggy Sunday Race.
- Game Deck is a particularly strong concept and should remain easy to understand.
- Sunday Race should work manually/local-first before any live-data automation is considered.

## Content structure
Each concept should quickly communicate:
1. Name
2. One-line pitch
3. How it works — this is the most important section and should receive the most visual space
4. Target audience
5. Number of players
6. Existing Corndoggy assets used
7. New assets required
8. Platform / digital or physical format
9. Repeat-use reason
10. What it adds to the Corndoggy universe
11. Build difficulty

Keep copy concise. Do not add new product concepts unless explicitly asked.

## Visual direction
- Friendly and playful, not corporate.
- Warm off-white background, dark text, restrained accents.
- Avoid large colorful blocks containing single words.
- Use whitespace, typography, thin borders and small playful details instead.
- Corndoggy artwork can later replace placeholder decorative elements.
- Mobile layout should remain highly scannable.

## Technical direction
- Static HTML/CSS is preferred unless interaction is required.
- Keep dependencies minimal.
- Preserve responsive behavior.
- Avoid introducing frameworks without a clear reason.
- If interactive prototypes are added, prefer local state and browser/device storage before introducing backend services.
